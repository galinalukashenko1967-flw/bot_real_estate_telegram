# Ідеї для розвитку продукту

Записано після обговорення MVP, ринкового аналізу та перевірки доступності
API основних майданчиків нерухомості. Статус: **не реалізовано, для
опрацювання**.

## Контекст: що з'ясували про ринок

**Україна** — LUN.ua та OLX вже сильні гравці:
- OLX має офіційне [Partner API](https://developer.olx.ua/api/doc), але
  воно радше для публікації/керування власними оголошеннями, ніж для
  читання чужих
- DIM.ria має портал [developers.ria.com](https://developers.ria.com/) з
  довідниками (регіони/міста), публікаційного read-API для оголошень
  офіційно не знайдено
- LUN.ua публічного партнерського API не має, сам є агрегатором
  (об'єднує дублікати оголошень різних рієлторів через власний AI)
- Висновок: прямої "відкритої" мультиджерельної агрегації через офіційні
  API з коробки не вийде — потрібні або комерційні перемовини з кожним
  майданчиком, або технічний парсинг (юридичні/технічні ризики)

**Чорногорія** — ринок протилежний до українського:
- Немає централізованого MLS і немає домінантного агрегатора (як LUN в
  Україні)
- Кожна агенція веде свою базу окремо; основні майданчики: nekretnina.me,
  keynekretnine.me, estitor.com, renekretnina.me
- Жоден не має публічного API
- Це означає: покриття ринку потребує кількох парсерів (не менше, а
  більше, ніж в Україні) **або** прямих партнерств з невеликою кількістю
  агенцій (реальніше, бо гравців мало)
- Основна аудиторія — іноземні покупці (укр/рос/серб/європейці), часто з
  прицілом на ВНЖ через покупку нерухомості

## Ідеї для ринку України

Не намагатись конкурувати з LUN/OLX за агрегацію — закрити те, чого в них
немає:

1. **Юридична перевірка об'єкта "із коробки"** — інтеграція з публічним
   Держреєстром речових прав на нерухоме майно: автоматична перевірка
   власника, обтяжень/арештів. Вирішує страх (особливо актуально під час
   війни — пошкоджена нерухомість, спірні права), а не просто зручність.
   Жоден з відомих конкурентів цього не робить.

2. **Голосові повідомлення на вхід** — AI транскрибує голосове і одразу
   витягує параметри запиту. Дрібна, але відчутна перевага для аудиторії,
   яка звикла писати голосом (особливо старше покоління).

3. **AI-оцінка вартості на основі власного датасету реакцій** — не
   "покажи оголошення", а "скільки насправді коштує моя квартира" —
   миттєва відповідь продавцю на основі внутрішньої бази + спарсених цін
   + **історії реакцій клієнтів на конкретні ціни** (це саме той сигнал,
   якого немає в публічних оголошеннях і немає у конкурентів — росте сам
   собою з кожним новим лідом).

4. **Рух далі по воронці, не тільки показ оголошення** — бот сам ініціює
   наступний крок (уточнює актуальність в продавця, готує чек-лист/
   документи для угоди), а не зупиняється на "показав варіант".

5. **Мультиканальність: Viber, не тільки Telegram** — частина аудиторії
   (40+) все ще звичніша до Viber. Архітектура вже дозволяє додати другий
   канал без переписування бізнес-логіки.

## Ідеї для ринку Чорногорії

Тут навпаки — реальне вікно стати першим агрегатором, бо домінантного
гравця немає:

1. **Мультиджерельний агрегатор** — зібрати 4-5 майданчиків
   (nekretnina.me, keynekretnine.me, estitor.com, renekretnina.me) в один
   пошук через AI-бота. Те, чого там фізично ні в кого немає.

2. **Багатомовний діалог (укр/рос/англ/чорногорська)** — основний попит
   іноземний, зараз це закривають тільки живі агенти-перекладачі. AI,
   що веде діалог кількома мовами — пряме влучання в біль.

3. **Фокус на 3-4 прибережних міста** (Будва, Котор, Тиват, Бар), а не
   всю країну — там концентрується попит іноземців.

4. **Партнерства замість парсингу** — гравців мало, реальніше
   домовитись напряму з кількома агенціями про фід даних, ніж з
   українськими гігантами.

## Наступний крок (рішення від 2026-09-17)

Вирішено спробувати **багатомовний варіант для Чорногорії** —
подивитись, яка там реально ситуація з майданчиками/агенціями, перш ніж
проектувати архітектуру.
